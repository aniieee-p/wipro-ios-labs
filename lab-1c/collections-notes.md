
# Lab 1C – Collections and Enums

## 1. Array
- An Array stores multiple values in an ordered sequence.
- It allows duplicate elements.
- Elements can be accessed using their index.
- Best used when maintaining an ordered list of items, such as course names.

## 2. Set
- A Set stores unique values.
- It automatically removes duplicate elements.
- It does not guarantee a specific order.
- Best used when storing unique student IDs or checking whether an element exists.

## 3. Dictionary
- A Dictionary stores data as key-value pairs.
- Each key must be unique.
- Values can be accessed using their corresponding keys.
- Best used when mapping student IDs to marks or storing related information.

## 4. Enum
- An Enum defines a fixed group of related values.
- It makes code easier to read and maintain.
- A switch statement can handle each enum case.
- Best used for fixed options such as task priorities or order statuses.

## Conclusion
Arrays are useful for ordered collections, Sets for unique values, and Dictionaries for key-value relationships. Enums represent a fixed group of related choices.
